# ContextWeft

**Portable, permission-aware context for every AI agent.**

> Status: planning / pre-alpha. ContextWeft is not ready for production use yet.

ContextWeft is an open-source context control plane that lets people and teams
carry verified work state, enterprise knowledge, and long-term memory across AI
agents, editors, models, and sessions.

It is designed to answer one practical question:

> When I switch agents, can the next agent continue the work without receiving
> the previous chat transcript or rediscovering the entire project?

## Current status

ContextWeft is currently in the planning and repository-bootstrap stage. There
is no usable implementation or release yet.

Public technical and product documentation will be added incrementally with
the code it describes. The repository will not publish speculative full-product
requirements as if they were implemented behavior.

ContextWeft intends to use
[OpenContext](https://github.com/melandlabs/opencontext) as its default context
runtime while keeping its public contracts engine-independent. This direction
is not yet implemented.
