# Changelog

## 0.1.0-alpha.1 — release candidate

- Added versioned contracts, a canonical SQLite event log, Git snapshots, and deterministic ContextPacks.
- Added local OpenContext-derived memory, the CLI, and eight MCP tools for checkpoint and bootstrap workflows.
- Added setup guidance for Codex, Cursor, and Claude Code, plus subprocess and package-install smoke tests.
- Updated dependencies and retained the 100% branch coverage gate with Vitest 5.

This candidate has not been published. Public APIs may change during the alpha series.
